Read it this way

One thing has been on every single paper: source coding. Shannon–Fano, Huffman, or both. In 2025 it was both, as two separate five-mark questions — a third of the entire paper. Learn the procedure until it is automatic, and always finish with all four numbers: average length L, entropy H, efficiency η = H/L, and redundancy 1 − η. Then check the Kraft sum, because the 2025 paper asked for it explicitly.

Then read the 2025 paper carefully, because it changed shape. Eight questions instead of five or six. Twenty of its thirty marks were drawing and explaining: line codes, ASK/FSK/PSK, a BPSK block diagram, a duobinary waveform, the system block diagram. The heavy information-theory numericals of 2022–2024 — capacity from SNR, delta-modulator entropy, PCM signalling rates — did not appear at all.

What that means for 2026. The safe reading is that 2025 set the new pattern under the new code, so waveforms and block diagrams carry most of the paper. The unsafe part is assuming the numericals are gone for good: they are still on the syllabus, they were the whole paper for three years running, and they are cheap to revise. Our predicted paper therefore follows the 2025 shape but keeps two numericals in it.

Where the drawing marks actually go. Every waveform question names a specific bit stream — 1011001 in 2025 — and expects the grid: bit boundaries ruled first, bits written above them, a whole number of carrier cycles per bit. A tidy grid is most of the mark, and it is the easiest mark on the paper to drop.

1
What is Inter Symbol Interference (ISI)? Why does it occur? Discuss Nyquist’s first criterion for achieving zero ISI.CO1
Solution

What it is. ISI is the smearing of one transmitted symbol into the time slots of its neighbours, so that the value sampled for one bit is contaminated by the tails of the bits around it.

Why it occurs. Every real channel is bandwidth limited. A sharp rectangular pulse contains frequencies out to infinity; passing it through a channel that removes the high frequencies spreads it out in time. The pulse that arrives is wider than the one that was sent, so its tail is still present when the next symbol is sampled.

The picture that explains it

Shout a word in a large empty hall. The echo of the first word is still bouncing around when you say the second, and the listener hears a muddle. ISI is exactly that, in electrical form — and it gets worse the faster you talk, which is why ISI is what ultimately limits the bit rate.

Nyquist’s first criterion. The cure is not to send rectangles. Instead send a pulse shaped so that it is zero at every neighbouring sampling instant:

p(t) = 1 at t = 0 p(t) = 0 at t = n Tb for every n other than 0

The pulse may spread out in time as much as it likes — at the exact moments when its neighbours are sampled, it contributes nothing. In the frequency domain the same condition reads:

sum over k of P(f + k/Tb) = Tb (constant, for all f)

which says the shifted copies of the pulse spectrum must add up to a flat line.

The minimum bandwidth this allows is the Nyquist bandwidth:

B_min = Rb / 2 Hz

The ideal brick-wall (sinc) pulse achieves exactly that, but it is unbuildable and its tails decay so slowly that a tiny timing error re-introduces huge ISI. The practical answer is the raised cosine pulse:

B = (Rb / 2)(1 + alpha) 0 <= alpha <= 1

with the roll-off factor α trading bandwidth against tolerance of timing error. Real systems use α = 0.2 to 0.5.

Design the Unipolar NRZ, Unipolar RZ, Polar NRZ, Polar RZ, Bipolar (AMI) and Manchester line coding schemes for the bit sequence 1 0 1 1 0 0 1. Which of these methods can be used for error detection, and which can be used for time synchronisation?CO1
Solution

Rule the seven bit boundaries first, and for the RZ codes mark the half-bit points too.

bit : 1 0 1 1 0 0 1 UNIPOLAR NRZ (1 = +A whole bit, 0 = 0) +A |___| |___|___| |___| 0 | |_____| |_____|_____| | UNIPOLAR RZ (1 = +A for half a bit, 0 = 0) +A |_| |_| |_| |_| 0 | |_______| |_| |_____________| |_ POLAR NRZ (1 = +A, 0 = -A) +A |___| |___|___| |___| 0 | | | | | -A | |_____| |_____|_____| POLAR RZ (1 = +A/2 half bit, 0 = -A/2 half bit, then 0) +A/2 |_| |_| |_| |_| 0 | |__ __| |_| |__ ___ __| |_ -A/2 | |_| |_| |_| BIPOLAR AMI (1s alternate +A / -A, 0 = 0) +A |___| |___| 0 | |_____| | |_____|_____| -A | |_____| |___| (+A) 0 (-A) (+A) 0 0 (-A) MANCHESTER (1 = low-to-high mid-bit, 0 = high-to-low mid-bit) +A | _| |_ _| _| |_ |_ _| 0 | | | | | | | | | | | | | | | -A |_| |_| |__| | | |__| |__|

For AMI, pencil the polarities before you draw. The 1s are at positions 1, 3, 4 and 7, so they take +A, −A, +A, −A in that order. The 0s sit on the zero line and are skipped in the counting.

Which can detect errors? Bipolar AMI

AMI has a built-in rule: successive 1s must alternate in polarity. If the receiver ever sees two +A pulses in a row with no −A between them, that is an AMI violation and an error has occurred. No extra bits are needed — the detection is free, and it comes from the coding itself.

Which can synchronise the clock? Manchester (and, partly, the RZ codes)

  • Manchester is fully self-synchronising: there is a guaranteed transition in the middle of every bit, whatever the data, so the receiver can always recover the clock. That is why it costs double the bandwidth.
  • RZ codes give a transition inside every 1, which helps, but unipolar RZ gives nothing during a long run of 0s.
  • NRZ codes are the worst: a long run of identical bits holds the line flat, the receiver’s clock drifts, and it loses count. This is exactly why scramblers exist.

Design the block diagram of BPSK modulation and demodulation. Explain the work of each block.CO1
Solution
MODULATOR binary data ---> [ NRZ level ] ---> (X) ---> [ band pass ] ---> BPSK out (unipolar) [ converter ] ^ [ filter ] | [ carrier oscillator ] (balanced modulator) DEMODULATOR (coherent) BPSK in ---> [ band pass ] ---> (X) ---> [ low pass ] ---> [ sample ] ---> data [ filter ] ^ [ filter ] [ + decide] | [ carrier recovery ]
BlockIts job
NRZ level converterTurns unipolar data (0 V, +V) into polar data (−V, +V). This is the step that makes the phase flip possible — a 0 must become a negative number, not zero.
Carrier oscillatorGenerates the reference sine wave at fc.
Balanced modulatorA product modulator. Multiplying by +V leaves the carrier alone; multiplying by −V inverts it — which is the 180° phase shift. Called balanced because the carrier itself is suppressed in the output.
Band pass filter (Tx)Removes the out-of-band products and limits the transmitted spectrum to its channel.
Band pass filter (Rx)Passes the wanted channel, rejects noise and neighbouring channels before anything else is done.
Carrier recoveryRegenerates a local carrier locked in frequency and phase to the incoming one. BPSK is coherent, so this is essential — a 180° lock error inverts every bit.
Balanced modulator (Rx)Multiplies the received signal by the recovered carrier. Since cos²θ = ½(1 + cos2θ), this gives the wanted baseband term plus a component at 2fc.
Low pass filterThrows away the 2fc component and leaves the data.
Sample and decideSamples once per bit at the best instant and compares with a threshold of zero: positive → 1, negative → 0.
The extra sentence worth writing

Because +cos and −cos look identical to a recovery loop that has just started, the receiver can lock 180° out and decode every bit backwards. The standard cure is differential encoding — send the change rather than the value — which gives DPSK, at a cost of roughly 3 dB in noise performance.

6
Draw the duobinary signal for the sequence 1 0 1 1 0 1. Explain how the same sequence is decoded at the receiver from the received duobinary signal.CO1
Solution

Step 1 — precode. Duobinary is used with a precoder so that a single sample error cannot propagate. The precoder is a running XOR:

p(k) = d(k) XOR p(k-1) starting from p(-1) = 0 d : 1 0 1 1 0 1 p : 1 1 0 1 1 0 p0 = 1 xor 0 = 1 p1 = 0 xor 1 = 1 p2 = 1 xor 1 = 0 p3 = 1 xor 0 = 1 p4 = 0 xor 1 = 1 p5 = 1 xor 1 = 0

Step 2 — map to polar and add the neighbour. Take 1 → +1 and 0 → −1, then form y(k) = a(k) + a(k−1), which is the controlled ISI duobinary deliberately introduces:

a : +1 +1 -1 +1 +1 -1 (a(-1) = -1, since p(-1) = 0) y(0) = +1 + (-1) = 0 y(1) = +1 + (+1) = +2 y(2) = -1 + (+1) = 0 y(3) = +1 + (-1) = 0 y(4) = +1 + (+1) = +2 y(5) = -1 + (+1) = 0 y : 0 +2 0 0 +2 0

The waveform takes only three levels — −2, 0 and +2:

+2 | ___ ___ 0 |___| |___|___| |___ -2 | d=1 d=0 d=1 d=1 d=0 d=1

Step 3 — decoding, which is the last mark. The decision rule needs no memory at all:

if y(k) = 0 -> d(k) = 1 if y(k) = +2 or -2 -> d(k) = 0
y : 0 +2 0 0 +2 0 d : 1 0 1 1 0 1 -- the original sequence

Recovered exactly: 1 0 1 1 0 1

Two things worth adding

Why precode at all. Without the precoder, decoding needs the previous decision, so one error would propagate forever. With it, every symbol is decided on its own sample alone.

Free error detection. Successive non-zero samples must alternate in polarity when separated only by zeros. Two +2s in a row with only zeros between them means an error has occurred — no extra bits required.

And the real prize: duobinary achieves the theoretical minimum bandwidth Rb/2 with a realisable filter, which the ideal brick wall is not.

They tie here — different codewords, identical average length. That happens often with well-behaved probabilities, and it does not mean the two methods are equivalent.

The sentence that earns the comparison mark

Huffman is provably optimal; Shannon–Fano is not. Huffman can never be beaten for a given set of probabilities, whereas Shannon–Fano can fall short when the splits cannot be made evenly. Here they happen to tie, but on a less friendly source Shannon–Fano loses — which is exactly why JPEG, MP3 and ZIP all use Huffman.

Also worth saying: Huffman codes are not unique. Swapping the 0/1 labels or breaking a tie the other way gives different codewords with the same L. If your codewords differ from a friend’s but your L matches, you are both right.

Solution

The BSC. Two inputs, two outputs, and one number describes it: p, the probability that a bit is flipped.

1-p 0 ------------> 0 \ p / \ / X channel matrix | 1-p p | / \ | p 1-p | / p \ 1 ------------> 1 1-p

Capacity. With equiprobable inputs, H(Y) = 1 bit, and the conditional entropy H(Y|X) is the entropy of the noise:

C = 1 + p log2 p + (1-p) log2 (1-p) = 1 - H(p) where H(p) is the binary entropy function

Read the shape: capacity = 1 minus what the noise steals. The two log terms are always negative, and together they are exactly the entropy the channel injects.

Answer any two: (i) …… line coding suppresses the DC component. (ii) The ARQ system with the highest throughput efficiency is …… and the one with the lowest is ……. Solution

(i) Bipolar (AMI) — and Manchester also qualifies. AMI works because successive 1s alternate in polarity, so the long-run average is zero. Manchester works because every bit contains one half at each level.

(ii) Highest: Selective Repeat · Lowest: Stop-and-Wait

In words: how much the uncertainty about X is reduced by observing Y. It is symmetric, it is never negative, and it is zero exactly when X and Y are independent. Maximising it over the input distribution gives the channel capacity.
