Signals: from analog to digital

What a signal is, how we sort signals into types, what "frequency" means once time becomes a list of numbers, how an analog signal is turned into that list, and the basic discrete-time signals we will use for the rest of the course.

1.1Signals and systems

A signal carries information. A system takes a signal in and gives another one out.

Module 01 · Review of Signal & System, §3–4
Definitions

A signal is a mathematical description of a physical happening that carries information. It is written as a function of one or more independent variables.

A system is a physical device or a mathematical operation that takes an input signal, processes it, and produces an output signal: y(t) = T{x(t)}.

  • One variable (time): s(t) = 5t, or a speech waveform.
  • Two variables (space): an image, I(x, y) — the value is brightness at a point.
  • Real signals like speech, ECG, EEG or a seismic recording are measured, not written as a formula.

Speech is a good example. Over a whole sentence it keeps changing, but over any short frame of 10–30 ms it barely changes, so each frame can be modelled as a sum of sinusoids:

s(t) = NΣi=1 Ai(t) sin(2πFi(t) t + θi(t))

A fresh set of {Ai, Fi, θi} is found for every frame. This is how every speech coder works.

A signal comes from a source — a physical stimulus plus the thing that responds to it. Vocal cords make speech; heart muscle makes an ECG. Measuring the signal tells you about the source, which is the whole point.

A system acts on it. The teacher's example: speech with noise on it, x(t) = s(t) + n(t), goes through a filter designed so that the output is y(t) ≈ s(t). The filter suppresses the noise and keeps the useful information. Filters, amplifiers, compressors and modulators are all systems in this sense.

1.2What DSP is, and its basic elements

Turn the signal into numbers, then do arithmetic on the numbers.

Module 01 · §5–7
Definition

Digital Signal Processing is the analysis and manipulation of signals using digital computers or dedicated digital processors, by carrying out mathematical operations on a digitised signal.

A DSP system is not tied to a box of hardware. It can be software on an ordinary computer, dedicated hardware (a DSP chip, an FPGA, an ASIC), or a mix of both. The recipe it runs — a finite sequence of mathematical operations — is called an algorithm. Filtering, the FFT, compression, noise reduction and feature extraction are all algorithms.

A/D converter (ADC)
Turns the analog signal into digital samples. Three steps inside: sample, quantize, code (§1.9–1.10).
DSP processor
Executes the signal-processing algorithm.
D/A converter (DAC)
Rebuilds an analog signal from the processed numbers.

1.3Advantages and limitations of DSP

Digital wins on flexibility, accuracy and reliability — analog still wins on raw speed.

Module 01 · §8–9

Advantages

  1. Programmable — change the algorithm in software; no hardware redesign.
  2. High accuracy — better precision and repeatability than analog components allow.
  3. Reliable storage — digital signals can be stored, copied and transmitted with no real loss.
  4. Advanced algorithms — FFT, adaptive filtering, image compression are all practical.
  5. Cost-effective — modern DSP processors give high performance for little money.

Limitations

  • High-speed A/D and D/A converters are needed.
  • Very wideband signals need very powerful DSP hardware.
  • Quantization brings finite-precision errors that cannot be avoided.
  • Real-time work needs enough computing power and memory to finish each sample before the next arrives.
  • Power consumption can be large in high-performance systems.
The sentence to end the answer with

For extremely high-frequency or ultra-wideband applications, analog processing may still be preferred, because the converters and the processor cannot keep up. Writing this shows you understand the trade-off rather than just listing benefits.

1.4Classification of signals

We sort signals into types because the method that works on one type often fails on another.

Module 01 · §11–15

The way we process a signal, or analyse how a system responds to it, depends heavily on the signal's characteristics. Some techniques only apply to particular families. So classifying is the first step, not decoration.

Continuous-time vs discrete-time

Continuous-time: defined at every instant, −∞ < t < ∞. Written x(t). Voltage, temperature, speech.

Discrete-time: defined only at particular instants, n = 0, ±1, ±2, …. Written x(n). Obtained by sampling. Digital audio, sensor readings.

Continuous-valued vs discrete-valued

Continuous-valued: the amplitude can be any value in a range — infinitely many possible levels. A microphone output.

Discrete-valued: the amplitude is limited to a fixed set of levels. Produced by quantization. Binary data, an ADC output.

The definition that gets examined

A digital signal is discrete in time and discrete in value. Sampling gives the first; quantization gives the second. Discrete-time alone is not digital.

Deterministic vs random

Deterministic: completely described by a formula or a table, so every future value can be predicted exactly. No uncertainty. A sine wave, a square wave, an exponential.

Random: values cannot be predicted; each observation is one possible realisation. Described with probability and statistics. Noise, real speech, thermal fluctuation.

Multichannel and multidimensional

A multichannel signal is several synchronised signals from the same event, written as a vector. The teacher's example: an earthquake sensor records ground acceleration in three directions, S(t) = [s1(t), s2(t), s3(t)]T. A 12-lead ECG has 12 channels.

A multidimensional signal depends on two or more independent variables. An image I(x, y) is 2-D; a video I(x, y, t) is 3-D.

SignalChannelsDimensions
Speech11-D

A colour TV picture is therefore a three-channel, three-dimensional signal. More channels or dimensions means a more expensive algorithm.

1.5Frequency in continuous time

Frequency means how fast something repeats — and for an analog sinusoid there is no limit.

Module 01 §16–20 · Teacher module M01L003

Two facts make sinusoids the most important signals in the course:

  1. Any signal can be written as a combination of harmonics — a periodic one from harmonics at separate frequencies (Fourier series), an aperiodic one from harmonics at all frequencies (Fourier transform).
  2. The response of a linear system to a harmonic input is a harmonic at the same frequency. That is what makes frequency-domain analysis possible.
xa(t) = A cos(Ωt + θ) = A cos(2πFt + θ),    −∞ < F < ∞
A

Ω = 2πF

θ

Tp = 1/F
the period. Raising F shortens the period — more oscillations in the same time.
Three properties of the analog sinusoid
  1. It is periodic for every F: xa(t + Tp) = xa(t).
  2. Sinusoids with different F are always different.
  3. Raising F raises the rate of oscillation without limit.

Keep these three in mind. In §1.6 all of them break.

As a complex exponential

A cos(Ωt + θ) = A2e j(Ωt+θ) + A2e−j(Ωt+θ)

Two phasors: the +Ω one rotates anticlockwise, the −Ω one clockwise, and their sum is the real cosine. This is why negative frequency appears in every spectrum — it is bookkeeping that keeps the answer real.

Phase delay

A cos(Ω0t + θ) = A cos[Ω0(t − tpha)],    tpha = −θΩ0

A phase angle is just a time shift. The waveform is unchanged; it only slides along the axis.

A combination of sinusoids

When is a sum of sinusoids periodic?

Only when the ratio of every pair of periods (or frequencies) is a rational fraction. Then the common period is the LCM of the individual periods, and the fundamental frequency is the GCD of the individual frequencies. Power simply adds: Py = Px1 + Px2 + …

If a ratio is irrational — 2cos(πt) + 4sin(3t) — there is no common period. Such a signal is called almost periodic.

WorkedCommon period of a sum (teacher's example)

x(t) = 2sin(3t) + 4cos(½t) + 4cos(⅓t − π/5)

periods:   T1 = 2π/3,   T2 = 4π,   T3 = 6π
common period T = LCM = 12π seconds
fundamental Ω0 = 2π/T = 1/6 rad/s  = GCD(3, ½, ⅓)

Check: 3 ÷ (1/6) = 18, ½ ÷ (1/6) = 3, ⅓ ÷ (1/6) = 2 — all whole numbers, so every part completes whole cycles in 12π s ✓

1.6Frequency in discrete time

Once time is a list of whole numbers, frequency behaves strangely — all three analog facts fail.

Module 01 §21–22 · Teacher module M01L003 §6–7

Sample the analog sinusoid every Ts seconds, so t = nTs:

x(n) = A cos(2πF nTs + θ) = A cos(2πFFsn + θ) = A cos(2πfn + θ) = A cos(ωn + θ)
The digital frequencies
f = FFs  cycles per sample — the normalised frequency
ω = 2πf = ΩFs = ΩTs  radians per sample

Digital frequency is the analog frequency divided by the sampling rate.

Property 1 — periodic only if f is a fraction

For the sequence to repeat after N samples, 2πfN must be a whole number of turns, 2πk:

f = kN  a ratio of whole numbers, common factors cancelled

The period N is the denominator. And k means: it takes k full cycles of the analog wave to make one period of the sampled sequence. A combination of DT sinusoids has period equal to the LCM of the individual periods.

Not every DT sinusoid is periodic

If f is irrational (e.g. f = √3, or sin(3n) where f = 3/2π) the sequence never repeats. It still has a periodic-looking envelope, but no true period.

Property 2 — frequencies 2π apart are the same signal

cos[(ω0 + 2π)n + θ] = cos(ω0n + 2πn + θ) = cos(ω0n + θ)

because 2πn is always a whole number of turns. So ω0 and ω0 + 2kπ are indistinguishable. A DT sinusoid is always periodic in frequency with period 2π (or 1 in f), and it is unique only in the principal range −½ ≤ f ≤ ½. If f0 > ½, the unique frequency is f0 − M for the whole number M that brings it into range.

Property 3 — the fastest wiggle is at ω = π

1.7Aliasing

Two different frequencies that give exactly the same samples.

Module 01 §23, §30 · Teacher module M01L003 §8

The teacher's argument. Let π < ω0 < 2π and put ω2 = 2π − ω0. Then

A cos(ω2n) = A cos[(2π − ω0)n] = A cos(2πn − ω0n) = A cos(ω0n)

The two are the same sequence, so ω2 is an alias of ω0. That is why we only use 0 ≤ ω ≤ π (or −½ ≤ f ≤ ½).

In terms of analog frequencies

The highest digital frequency is f = ½, so the highest analog frequency a sampled signal can carry is Fmax = Fs/2 — the folding frequency. Every frequency Fk = F0 + k Fs gives the same samples as F0.

Worked10 Hz and 50 Hz at Fs = 40 Hz (teacher's example)

x1(t) = cos(2π·10t) and x2(t) = cos(2π·50t), sampled at 40 Hz.

x1(n) = cos(2π·1040n) = cos(π2n)
x2(n) = cos(2π·5040n) = cos(5π2n) = cos(2πn + π2n) = cos(π2n)

So x1(n) = x2(n): 50 Hz is an alias of 10 Hz at 40 Hz sampling. Once sampled, nothing can tell them apart.

1.8Harmonically related complex exponentials

A family of exponentials whose frequencies are whole-number multiples of one fundamental — the bricks every Fourier method is built from.

Module 01 §24–25 · Teacher module M01L003 §9–10

Continuous time — infinitely many

sk(t) = e jkΩ0t = e j2πkF0t,   k = 0, ±1, ±2, …

Each is periodic with period Tp/k, and every different k is a different signal, so there are infinitely many. A linear combination

xa(t) = ∞Σk=−∞ ck e j2πkF0t

with period Tp = 1/F0 is the Fourier series.

Discrete time — only N of them

With f0 = 1/N, sk(n) = e j2πkn/N. But now

sk+N(n) = e j2π(k+N)n/N = e j2πkn/N·e j2πn = sk(n)
The fact that leads to the DFT

In discrete time there are only N distinct harmonics, k = 0, 1, …, N−1, all sharing the period N. So the discrete Fourier series is a finite sum:

x(n) = N−1Σk=0 ck e j2πkn/N

This is why the DFT of N samples has exactly N values (Unit 5).

1.9Sampling and the sampling theorem

Take a reading every T seconds. Do it faster than twice the highest frequency and you lose nothing.

Module 01 §27–29, §31

We use uniform (periodic) sampling:

x(n) = xa(nT),    Fs = 1/T,    t = nT = n/Fs
Continuous-timeDiscrete-timeLink
Ω rad/s, F Hzω rad/sample, f cycles/sampleω = ΩT, f = F/Fs

The Sampling Theorem

If the highest frequency in the analog signal is Fmax, choose

Fs > 2Fmax   so that every component has |f| = |F|/Fs < ½

FN = 2Fmax is the Nyquist rate. Sample slower and aliasing folds the high components down onto the low ones, permanently.

WorkedTeacher's review examples on sampling

(A) xa(t) = 3cos(100πt), so F = 50 Hz.

  1. Minimum rate to avoid aliasing: Fs = 2F = 100 Hz.
  2. At Fs = 200 Hz: x(n) = 3cos(πn/2) = 3cos(2π·¼n).
  3. At Fs = 75 Hz: x(n) = 3cos(4πn/3) = 3cos(2πn − 2πn/3) = 3cos(2π·⅓n).
  4. The sinusoid that gives the same samples as (3) without aliasing: F = f·Fs = ⅓ × 75 = 25 Hz, i.e. ya(t) = 3cos(50πt).

(B) xa(t) = 3cos(2000πt) + 5sin(6000πt) + 10cos(12000πt)

F1 = 1 kHz, F2 = 3 kHz, F3 = 6 kHz  ⇒  Nyquist rate = 12 kHz

Sample at only 5 kHz (folding frequency 2.5 kHz). 1 kHz survives; 3 kHz folds to 3 − 5 = −2 kHz; 6 kHz folds to 6 − 5 = 1 kHz:

x(n) = 3cos(2π·⅕n) − 5sin(2π·⅖n) + 10cos(2π·⅕n) = 13cos(2π·⅕n) − 5sin(2π·⅖n)

Ideal interpolation then gives back ya(t) = 13cos(2000πt) − 5sin(4000πt) — two components instead of three, and the 6 kHz one has landed on top of the 1 kHz one. That is the cost of aliasing.

(C) Module 01 exercise. An analog signal has frequencies up to 10 kHz.

  1. Exact reconstruction needs Fs ≥ 2 × 10 = 20 kHz.
  2. At Fs = 8 kHz the folding frequency is 4 kHz, so F1 = 5 kHz appears as 8 − 5 = 3 kHz.
  3. F2 = 9 kHz appears as 9 − 8 = 1 kHz.

1.10Quantization, coding and D/A

Sampling fixed the time axis. Quantization rounds each sample to the nearest allowed level, and coding writes that level in bits.

Δ = xmax − xminL − 1  step size (resolution), L = number of levels
eq(n) = xq(n) − x(n),    −Δ/2 ≤ eq(n) ≤ Δ/2  for rounding

Signal-to-quantization-noise ratio

With b bits over a range 2A, Δ = 2A/2b. Treating the error as a small ramp between levels, its power is Pq = Δ²/12, and for a full-scale sinusoid Px = A²/2:

SQNR(dB) = 10log10PxPq = 1.76 + 6.02 b

Every extra bit is worth about 6 dB.

Coding gives each of the L levels a b-bit binary word, b ≥ log2L.

Digital-to-analog conversion

All D/A converters interpolate. The simplest is the zero-order hold — hold each sample's value until the next one arrives, giving a staircase. Linear interpolation joins successive samples with straight lines, but needs a delay of T so it knows the next sample. Higher-order interpolation does better still.

1.11Writing down a discrete-time signal

Four ways to write the same list of numbers, and a few words for describing its shape.

Teacher module M01L001 §1–3

A discrete-time signal x(n) is a function of an integer n, the time index, with x(n) = xa(nTs). It is not defined for non-integer n. The teacher's example x(n) = {0, 0, 1, 4, 1, 0, 1} can be written:

  1. Graphically — a stem plot.
  2. Functionally — x(n) = 1 for n = −1, 1, 3; 4 for n = 2; 0 elsewhere.
  3. In a table — a row of n, a row of x(n).
  4. As a sequence — {…, 0, 0, 1, ↑4, 1, 0, 1, 0, …} with an arrow at n = 0.

1.13Operations on signals

Change the index n — shift, fold, scale — or change the value x(n) — scale, add, multiply.

Teacher module M01L001 §5–6

Time transformations of n

Time shift   y(n) = x(n − k)
k > 0: a delay — the signal moves right. k < 0: an advance. If x starts at n = N, x(n−k) starts at N + k. Check: a sample at old index n lands at the new index that makes the argument equal n.
Folding   y(n) = x(−n)
A mirror image about n = 0.
Time scaling   y(n) = x(Dn)
D > 1 whole number: decimation — keep every Dth sample. Information is lost. 0 < D < 1: interpolation — insert new samples (zero, step, or linearly interpolated values) between existing ones.
Two orders that matter

Fold and delay do not commute. With TD for delay and FD for fold:

FD{TDk[x(n)]} = x(−n − k)    but    TDk{FD[x(n)]} = x(−n + k)

Decimation is the inverse of interpolation, but not the other way round. Decimate then interpolate loses samples; interpolate then decimate returns the original. If you need both, interpolate first.

1.14Symmetry: even and odd parts

Discrete-time systems

A system is a rule that turns one sequence into another. This unit is about the rules worth studying — linear, time-invariant ones — and the three ways to find their output: recursion, the formal solution, and convolution.

2.1Building blocks and the input–output description

Every discrete-time system is wired from five parts, and its wiring can be written as a difference equation.

Teacher module M02L002 §3–5

In the time domain most discrete-time systems are modelled by a difference equation — for example y(n) = y(n−1) + x(n), whose output is the previous output plus the present input. Such an equation only ever uses shifted signals, added signals, multiplied signals and scaled signals, so five blocks are enough to draw any of them.

2.2Linearity and superposition

A linear system treats a sum of inputs as a sum of outputs. That one property makes every method in this course work.

Teacher module M02L002 §6
additive:    T{x1(n) + x2(n)} = T{x1(n)} + T{x2(n)}
homogeneous:    T{K·x(n)} = K·T{x(n)}
linear = both:    T{A·x1(n) + B·x2(n)} = A·T{x1(n)} + B·T{x2(n)}

Anything that fails this is non-linear. Superposition of linear transformations is itself linear, so a chain of linear systems is linear.

Why we care

If x(n) = Σ akxk(n) then y(n) = Σ akyk(n). So: break the input into simple pieces, find the response to each piece, add. Convolution does this with impulses as the pieces (§2.11); the DTFT does it with complex exponentials as the pieces (Unit 4).

The time-invariance test

Delay the input by k and compute the response y(n,k) = T[x(n−k)]. Separately delay the original output to get y(n−k). Equal for every k → time-invariant. Not equal for even one k → time-variant.

WorkedThree tests from M02L002

Differentiator y(n) = x(n) − x(n−1): y(n,k) = x(n−k) − x(n−k−1) and y(n−k) = x(n−k) − x(n−k−1). Equal → time-invariant.

Time multiplier y(n) = n x(n): y(n,k) = n x(n−k) but y(n−k) = (n−k)x(n−k). Different → time-variant.

Folder y(n) = x(−n): y(n,k) = x(−n−k) but y(n−k) = x(−n+k). Different → time-variant.

LTI systems, and how to spot a non-LTI equation at a glance

A linear time-invariant (LTI) system is one described by a linear constant-coefficient difference equation:

y(n) + a1y(n−1) + … + aNy(n−N) = b0x(n) + b1x(n−1) + … + bMx(n−M)

Every term contains x or y, every coefficient is a constant, and the leading coefficient is 1. N (the largest output delay) is the order.

  • Non-linear if any term is a constant, or a product / power / function of x or y (e.g. x²(n), x(n)y(n−1), +3).
  • Time-varying if any coefficient is a function of n (e.g. n·x(n), cos(ωn)x(n)), or if the index is scaled or folded (x(2n), x(−n)).

Causality from the equation

It is non-causal if the least-delayed output term sits beside an input term x(n+k) with k > 0. Teacher's list:

Stability from the characteristic roots

BIBO stability

For an LTI difference equation, a necessary and sufficient condition is that every root of the characteristic equation has magnitude less than 1.

  • y(n) − ⅙y(n−1) − ⅙y(n−2) = x(n): characteristic equation z² − ⅙z − ⅙ = 0, roots ½ and −⅓ → stable.
  • y(n) − 2y(n−1) + y(n−2) = x(n): repeated root at 1 → unstable.

2.5FIR and IIR systems

Feed the system one impulse. If the output dies out after a finite number of samples it is FIR; if it goes on forever it is IIR.

The impulse response decides

One equation, two impulse responses. Which one you mean is decided by the region of convergence of the z-transform — Unit 3.

Stability

Three equivalent statements
  • BIBO stable: every bounded input gives a bounded output.
  • For an LTI difference equation: every characteristic root has magnitude < 1 (complex roots: |λ| < 1). Then the natural response always decays and the forced response stays bounded.
  • For an impulse response: Σ|h(n)| < ∞ — absolutely summable.

Roots on the unit circle make the system unstable: a simple unit-magnitude root gives a bounded natural response but a ramp or growing sinusoid when driven at the same frequency; a repeated one grows on its own. FIR filters are always stable — a finite weighted sum of bounded inputs is bounded.

2.11Convolution: where it comes from

Break the input into impulses, let the system answer each one, add the answers. That is all convolution is.

Teacher module M02L005 §1–3
Key result

For a relaxed LTI system, the output is the input convolved with the impulse response:

y(n) = x(n) ∗ h(n) = ∞Σk=−∞ x(k) h(n−k)

Once you know h(n), you know the zero-state response to every input.

The derivation, in three lines

Line 1 — any signal is a sum of impulses (§1.15): x(n) = Σk x(k)δ(n−k). Teacher's example: x(n) = {2, ↑4, 0, 3} = 2δ(n+1) + 4δ(n) + 3δ(n−2).

Line 2 — linearity lets the system act on each impulse separately:

y(n) = T{Σk x(k)δ(n−k)} = Σk x(k) T{δ(n−k)}

Line 3 — time invariance says a shifted impulse gives a shifted impulse response, T{δ(n−k)} = h(n−k). Substitute and you have the convolution sum. At one instant n0: y(n0) = Σk x(k)h(n0−k) — one number, from one multiply-and-add pass over k.

2.14Periodic inputs and circular convolution

A periodic input gives a periodic output. To handle repeating signals, let the index wrap around instead of running off the end.

Teacher module M02L005b §2–3

Teacher's example: x = {1, 2, −3, 1, 2, −3, …} (period 3) into h = {1, 1}:

y = {1, 3, −1, −2, 3, −1, −2, 3, −1, …}

After the first sample the output is periodic with the same period, yp = {−2, 3, −1}. The direct way to that steady-state period: convolve one period of the input with h, then wrap the overflow back to the front:

{1, 1} ∗ {1, 2, −3} = {1, 3, −1, −3}  →  {1, 3, −1} + {−3, 0, 0} = {−2, 3, −1} ✓

Wrapping N-sample sections of a signal and adding them builds its periodic extension xpe(n) = Σkx(n+kN); a signal shorter than N is just zero-padded.

Periodic (circular) convolution
yp(n) = xp(n) Ⓠ hp(n) = N−1Σk=0 xp(k) hp[(n−k) mod N],   n = 0, …, N−1

Ordinary linear convolution of two periodic signals does not exist (the sum never converges), so this is what we use. Exactly N output samples, and the result is periodic with period N.

Why it matters: detection in noise, matched filtering, ranging

Noise is essentially uncorrelated with a signal. So correlating a noisy recording with the clean template produces a sharp peak where the template is present — the signal shows up even when it is buried. A filter whose impulse response is the folded template, h(n) = s(−n), does exactly this correlation by convolution: the matched filter. In radar, correlate the echo with the transmitted pulse; the lag of the peak is the round-trip delay, hence the target's range.

4.8Between the z-transform and the DTFT

Two substitution rules, and one warning about signals whose poles sit on the circle.

Teacher module M04L001, last slide
The rules
  • From X(z) to the DTFT: if x(n) is absolutely summable, replace z by ej2πF (or ejω).
  • From the DTFT to X(z): delete any impulse terms, then replace ej2πF (or ejω) by z.

Why impulses appear: u(n) and cos(ω0n) are not absolutely summable — their z-transforms have poles on the unit circle, exactly where the DTFT is evaluated. 5.2Frequency-domain sampling; choosing N

Two things stop a computer computing the DTFT. Fix both by sampling — and use a small trick with the index k.

Teacher module M04L002 §2–3
Why we can't just compute the DTFT (M04L002)
  1. The sum X(ω) = Σx(n)e−jωn runs over infinitely many n. Solved if the sequence is finite — the realistic case.
  2. X(ω) must be evaluated at infinitely many ω in (−π, π). Still a problem.

So we sample the spectrum: since X(ω) repeats every 2π, take N equidistant samples in 0 ≤ ω < 2π with spacing Δω = 2π/N — the frequency resolution.

Selecting N, and the mirror trick

Take a finite signal, x(n) = 0 for n < 0 and n ≥ N. We are really interested in −π ≤ ω < π; everywhere else the spectrum just repeats. Computing it at 8 points would be far too few — in practice thousands. Then the trick: do not compute the negative-ω points; compute their mirror images between π and 2π instead. Same numbers, but now the index runs 0, 1, 2, … instead of straddling zero, which makes every later formula tidy. So with M frequency points:

ωk = k·2πM,   k = 0, 1, …, M−1   ⇒   X(k) = N−1Σn=0 x(n)e−j2πkn/M

Padding zeros so that M = N gives the DFT proper, and forcing M = N is what makes the inverse work. The "upper" DFT points are really the negative frequencies — move them down when you plot.

What sampling the spectrum does to the time signal

The IDFT returns xp(n), which is periodic with period N. Sampling in frequency makes the time signal repeat (§4.1's rule), so if the signal is longer than N its tail wraps onto its head — time-domain aliasing, the mirror image of §1.7. Recovery is exact only when N ≥ the signal length.

5.6DFT and DTFT: the finite case

If the signal really is finite, the DFT points sit exactly on its DTFT — and zero padding just puts more dots on the same curve.

Teacher module M04L002 §6–7

The practical chain (M04L002): a sensor → ADC at Fs → N samples in memory → FFT → N DFT values in memory. So we need to know what those values say about the true spectrum. Two cases: the signal is finite (all its non-zero samples fit in our N), or infinite (it goes on longer than we can capture).

Finite case

If x(n) = 0 outside 0 … N−1, the DTFT sum has nothing to leave out, and comparing it with the DFT formula:

X(k) = X(ω)∥ω = 2πk/N  exactly — the DFT points lie ON the DTFT curve

N only sets how closely spaced the samples are. Zero-padding trick: tack zeros on the end so the total is Nz; the sums are unchanged (zeros add nothing) but the spacing becomes 2π/Nz, smaller than 2π/N: a denser set of samples on the same curve.

WorkedThe pulse example (M04L002)

Summary — finite-length signals (M04L002)
  • The DFT samples the DTFT at ωk = 2πk/N; the points lie exactly on the curve.
  • More points → a denser sampling → a better picture of the spectral shape.
  • Zero-padding does not change the DTFT or the spectral shape; it reduces the spacing 2π/N and gives a denser set of samples of the same curve.

5.8Cost of the direct DFT

Straight from the definition, an N-point DFT costs N² complex multiplications — and N² grows horribly.

Teacher module M04L004 §2–3

The DFT is used for linear filtering, correlation and spectrum analysis, so computing it efficiently matters. Two families of methods exist: divide and conquer, and DFT as linear filtering (§5.9). First, what the direct method costs. Write out one output:

X(k) = x(0)WN0 + x(1)WNk + x(2)WN2k + … + x(N−1)WN(N−1)k
Direct computation
per k: N complex multiplications, N−1 complex additions
total: N² complex multiplications,   N(N−1) complex additions

In real arithmetic — one complex multiply is 4 real multiplies and 2 real adds (write x = xR + jxI and W = cos − j sin):

4N² real multiplications  ·  2N(N−1) real additions  ·  2N² trigonometric evaluations

The trig functions hurt most; every real implementation stores the twiddles in a table.

The module's "little trick": to add 1 to 100, pair them off — 1 + 100, 2 + 99, … — fifty pairs of 101, so 50 × 101 = 5050 in one multiplication. The FFT is the same move: the direct DFT ignores the structure in WN (periodicity, symmetry, half-point — §5.3) and recomputes the same products over and over; the FFT does each piece of work once. It is not a different transform — it gives exactly the same X(k).

Same flow graph, conjugate twiddles, divide by N.

IFFT from either graph

Replace every WNk by WN−k and divide the result by N. Structure and cost are unchanged: (N/2)log2N multiplications, N log2N additions.

5.15Composite radix and divide-and-conquer

Radix-2, 3 and 4 are one idea with a different number; divide-and-conquer is the general method that works for any N that factorises.

Composite radix

If N = m1N1, split x(n) into m1 interleaved sub-sequences of N1 samples by taking every m1th sample:

X(k) = m1−1Σr=0 WNrk N1−1Σn=0 x(m1n + r) WN1nk
Radix-3 (N = 3v):   X(k) = Σnx(3n)WN/3nk + WNkΣnx(3n+1)WN/3nk + WN2kΣnx(3n+2)WN/3nk
Radix-4 (N = 4v):   X(k) = Σnx(4n)WN/4nk + WNkΣnx(4n+1)WN/4nk + WN2kΣnx(4n+2)WN/4nk + WN3kΣnx(4n+3)WN/4nk
Radix-3 and radix-4 in practice
  • Radix-3: log3N stages of 3-point butterflies; the 3-point twiddles 1, −½ − j0.866, −½ + j0.866 are not free. Reordering is digit reversal in base 3.
  • Radix-4: log4N stages of 4-point butterflies; the 4-point twiddles are 1, −j, −1, j — sign changes and real/imaginary swaps, free. That is why radix-4 needs about (3N/8)log2N multiplications, a quarter fewer than radix-2. Reordering is digit reversal in base 4.
  • If N is prime there is nothing to split; pad with zeros to a convenient length (harmless — §5.6).

Divide and conquer — the general method

Take N = LM (L rows, M columns) and store the N samples as an L × M table. Two natural mappings for the input index, and likewise for the output index:

row-wise: n = Ml + m     column-wise: n = l + mL      l = 0…L−1, m = 0…M−1
row-wise: k = Mp + q     column-wise: k = p + qL      p = 0…L−1, q = 0…M−1

Take the input column-wise (n = l + mL) and the output row-wise (k = Mp + q) and substitute into the DFT:

X(p, q) = M−1Σm=0L−1Σl=0 x(l, m) WN(Mp+q)(mL+l)     WN(Mp+q)(mL+l) = WNMLmp WNmLq WNMpl WNlq
WNMLmp = WNNmp = 1   ·   WNmLq = WMmq   ·   WNMpl = WLpl   ·   WNlq stays  the extra twiddle
Result
X(p, q) = L−1Σl=0 { WNlq [M−1Σm=0 x(l, m) WMmq] } WLlp

One N-point DFT has become DFTs of length M and L, with a twiddle multiplication between.
